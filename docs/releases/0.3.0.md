First published release of the unofficial Superwise integration for Home Assistant.

## Features

- Live kiln temperature, setpoint, heating output, controller temperature and process status.
- Automatic controller discovery. Select a kiln if the account contains more than one.
- JSON status polling alongside live updates, with timestamp-based availability.
- Program selection, start, stop, pause and continue controls.
- Program readback, segment temperature/dwell editing and firing-history actions.
- Estimated electrical power when kiln rated power is configured.
- Diagnostic error-code sensor and a direct link to the controller in SuperWise.
- Stored-session reuse and automatic renewal with the saved password. Rejected credentials require reauthentication.
- English and German translations.

## Installation

Requires **Home Assistant 2026.10 or newer**.

Add `https://github.com/jsaalfeld/superwise-home-assistant` to HACS as a custom
repository of type **Integration**, download Superwise and restart Home Assistant.
Then add Superwise under **Settings → Devices & services**.

For manual installation, extract `superwise.zip` into the Home Assistant
configuration directory. The resulting path must be
`custom_components/superwise/manifest.json`. Restart Home Assistant before setup.
`SHA256SUMS` contains the SHA-256 checksum of the ZIP.

Existing configurations keep their selected controller and entity IDs.

## Current limits

This is an experimental integration using undocumented SuperWise cloud interfaces.
Hardware checks were performed with a TC75 and Home Assistant 2026.10.2; other
controllers are unverified. Execution controls have been checked at protocol level
but still need supervised validation through the installed integration.

Remote control is disabled by default. Pause may leave the kiln heating; it is
not an off command. Command results are checked against controller feedback,
which is not independent current measurement. Commands are not automatically
repeated after an uncertain result or authentication failure.

Only one kiln per account can be configured. A renewed login may replace another
session for the same account. Power values in kW are estimates, not measurements;
no energy counter is included.

## Validation

The release workflow requires the test suite, HACS validation and hassfest to
pass before publishing. Automated tests use synthetic data and send no kiln commands.
